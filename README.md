# 周销量 Holt–Winters 补货预测工具

一个面向连锁便利店补货计划的内部 Web 工具。后端用 Python 3.12 + FastAPI + NumPy 手写 Holt–Winters 递推、参数优化、预测区间和滚动原点回测；前端用 React 18 + Vite + TypeScript；结果保存于 PostgreSQL 16。

## 启动

```bash
docker compose up --build
```

启动后打开：

- 前端：<http://localhost:8080>
- 后端 API 文档：<http://localhost:8000/docs>

CSV 为两列，无表头或中文/英文表头均可：

```csv
日期,销量
2025-01-06,1234
2025-01-13,1188
```

日期必须是连续的星期一（周起始日）。若缺周，前端会明确给出缺失的周起始日期，后端也会再次校验。仓库根目录附带 `sample_weekly_sales.csv`，可直接用于体验 52 周周期拟合和回测。

## 模型定义

记号：

- `y_t`：第 t 周销量；
- `m`：季节周期，周数据常用 52，也可手动指定；
- `l_t, b_t, s_t`：水平、趋势、季节状态；
- `α, β, γ ∈ [0,1]`：水平、趋势、季节平滑参数；阻尼模型还有 `φ ∈ [0,1]`。

支持六种组合：

1. 加法季节、无趋势；
2. 加法季节、加法趋势、无阻尼；
3. 加法季节、加法趋势、阻尼；
4. 乘法季节、无趋势；
5. 乘法季节、加法趋势、无阻尼；
6. 乘法季节、加法趋势、阻尼。

### 初值规则

只使用前两个完整季节，规则固定且可复现：

1. 计算第一、第二个季节的均值 `mean1`、`mean2`；
2. 有趋势模型：`b0=(mean2-mean1)/m`；无趋势模型 `b0=0`；
3. 以每个季节的中心时点去除线性趋势后，计算原始季节项：
   - 加法：`y_i-[season_mean+b(i-(m-1)/2)]`；
   - 乘法：`y_i/[season_mean+b(i-(m-1)/2)]`；
4. 对同一季节位置的两个原始项取算术平均；
5. 归一化：
   - 加法季节项总和为 0，并把均值平移到水平；
   - 乘法季节项均值为 1，并按比例调整水平；
6. 水平按第一期预测对齐：加法 `l0=y0-s0`，乘法 `l0=y0/s0`。

### 递推

令趋势推进后的水平为：

- 无趋势：`A=l_{t-1}`；
- 无阻尼趋势：`A=l_{t-1}+b_{t-1}`；
- 阻尼趋势：`A=l_{t-1}+φb_{t-1}`。

加法季节：

```text
ŷ_t = A + s_{t-m}
l_t = α(y_t-s_{t-m}) + (1-α)A
b_t = β(l_t-l_{t-1}) + (1-β)b*
s_t = γ(y_t-l_t) + (1-γ)s_{t-m}
```

其中无阻尼 `b*=b_{t-1}`，阻尼 `b*=φb_{t-1}`。

乘法季节：

```text
ŷ_t = A s_{t-m}
l_t = α(y_t/s_{t-m}) + (1-α)A
b_t = β(l_t-l_{t-1}) + (1-β)b*
s_t = γ(y_t/l_t) + (1-γ)s_{t-m}
```

乘法模型要求所有销量为正；若出现零或负值，或数据少于两个完整季节，服务拒绝拟合并返回原因。乘法递推中若出现非正状态也视为不可行参数。

### 参数优化与 AIC

目标函数是历史一步预测误差平方和 SSE：

```text
SSE = Σ(y_t-ŷ_t)^2
```

优化器不调用 statsmodels 等预测库。实现位于 `backend/app/holtwinters/optimizer.py`，为确定性的多起点有界 Nelder–Mead：参数被投影到 `[0,1]`，从边界点、常用网格点和默认点启动局部搜索，再取全局最小 SSE。锁定参数时，该参数固定，其余参数照常优化。

AIC 用高斯误差形式：

```text
AIC = n log(SSE/n) + 2k
```

`k` 为该模型使用的平滑参数个数。自动选型在六种组合中选择 AIC 最小者，页面同时列出所有可行组合分数。SSE 在无噪合成序列中可能为 0，代码用连续极限的保守有限值表示，避免 AIC 变成负无穷。

### 预测与区间

未来第 h 步：

- 无趋势：水平不变；
- 加法趋势：`l_h=l_T+h b_T`；
- 阻尼趋势：`l_h=l_T+(φ+...+φ^h)b_T`。

再取对应循环季节项相加或相乘。

区间使用解析正态近似。残差估计创新方差；加法模型直接使用误差，乘法模型使用一阶相对误差 `(y-ŷ)/ŷ`。创新通过水平、趋势和季节状态传播，得到随步长累计的方差系数。为满足业务要求，最终半宽还做 `cumulative max`，因此宽度对预测步长单调不减。默认 95% 区间，可在页面选择置信水平。

## 回测

给定起点后按滚动原点执行：

1. 原点 k 的训练集严格为 `y[0:k]`；
2. 用该训练集重新初值化、重新优化参数；
3. 向前预测 1..h 步；
4. 原点向前滚动 `step` 周后重复。

季节朴素基准为：

```text
ŷ_{k+j}=y_{k-m+j}
```

汇总 MAE、MAPE、MASE，并按步长和整体给出对照。MASE 的尺度只用当前原点训练集中的季节差分计算。测试通过向最后一个评估点之后注入极端值且回测结果不变，证明原点没有偷看未来。

## 模块结构

后端：

- `holtwinters/schema.py`：模型组合；
- `validation.py`：长度、正值等校验；
- `initialization.py`：两季节初值规则；
- `core.py`：递推和点预测；
- `optimizer.py`：有界多起点 Nelder–Mead；
- `intervals.py`：正态分位数与区间；
- `fitting.py`：单次拟合、SSE/AIC、自动选型；
- `backtest.py`：滚动原点、季节朴素基准、指标；
- `db/`：PostgreSQL schema 与仓储；
- `jobs.py`：后台线程任务与进度；
- `routes.py`：FastAPI 路由。

前端：

- `api/`：数据请求层；
- `utils/csv.ts`：CSV 解析与缺周检测；
- `hooks/`：任务轮询；
- `components/`：序列列表、参数面板、图表、拟合统计、回测页；
- `types.ts`：共享类型。

## 存储

PostgreSQL 表：

- `series`：序列、日期和销量；
- `fit_runs`：同一序列的每次拟合请求、状态、进度、参数、SSE/AIC、残差和最终状态；
- `backtests`：每次回测请求、逐原点结果和汇总指标。

多次拟合和回测均保留，可通过 `/api/series/{id}/runs` 相互比较。
